# Project Map

## Root
- `CalorieTrackerApp.swift` - app entry point and SwiftData `ModelContainer`.
- `project.yml` - XcodeGen project definition, including UI test target.
- `codemagic.yaml` - simulator build/tests, unsigned IPA, and screenshot workflows.
- `Info.plist` - permissions and app metadata.
- `.gitignore` - ignores downloaded Codemagic artifact folders.

## Folders
- `Configuration/` - theme preference and Gemini API configuration.
- `Models/` - SwiftData models and Codable AI estimate structs.
- `Services/` - network API layer.
- `Utilities/` - validation, image compression, backup, camera auth, nutrition calculations.
- `ViewModels/` - MVVM state and business logic.
- `Views/` - SwiftUI screens and reusable UI rows.
- `Tests/` - unit tests for Gemini requests, AI view models, SwiftData, backup, and validation.
- `UITests/` - screenshot automation.
- `docs/DEMO_CHECKLIST.md` - Codemagic and physical-iPhone release gate.
- `Assets.xcassets/` - app icon assets.

## Key Files
- `Models/DailyGoal.swift` - daily calorie/macro target and relationship to food items.
- `Models/FoodItem.swift` - meal entry model with calories, macros, grams, image data.
- `Models/DailyGoalTargets.swift` - persistent current diet targets.
- `Services/NetworkManager.swift` - Gemini image analysis and text nutrition guess.
- `Utilities/DailyGoalStore.swift` - canonical daily-goal fetch and duplicate-day consolidation.
- `ViewModels/AIRequestFailure.swift` - actionable user-facing AI error state.
- `Views/DashboardView.swift` - main calorie ring, streak bar, today food list.
- `Views/ManualEntryView.swift` - manual and AI Guess meal entry tabs.
- `Views/AICameraEntryView.swift` - photo/camera AI entry flow.
- `Views/HistoryView.swift` - week/month scoped history and calendar.
- `Views/StatisticsView.swift` - charts and deficit/surplus summary cards.
- `Views/SettingsView.swift` - profile, API key, theme, backup import/export.
- `UITests/ScreenshotUITests.swift` - captures main screens for Codemagic artifacts.
- `Tests/NetworkManagerTests.swift` - mocked Gemini status, schema, retry, cooldown, and cache tests.
- `Tests/PersistenceTests.swift` - diet target, duplicate-day, and backup round-trip tests.

## Ignore
Do not include `build/`, DerivedData, `.xcodeproj` generated by XcodeGen, downloaded `CalorieTracker_*_artifacts/`, or other build output.
